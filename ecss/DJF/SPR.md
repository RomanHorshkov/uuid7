# Software problem reports and nonconformance reports {#UUID7_DOC_SPR}

<!-- ecss:docinfo id=UUID7-DOC-SPRNCR -->

Problem reports and nonconformances are rms change-requests (\ref UUID7_DOC_SMP "SMP" <14>; ECSS-Q-ST-80 5.2.5, 5.2.6), listed here at every refresh, with the failed verification cases of this refresh, which each open one. The rms has no problem-report or nonconformance kind yet, so the change requests stand in, without the fields of ECSS-Q-ST-80 5.2.5.2; the deviation from coding rule N3 (\ref UUID7_DOC_SPAMR "SPAMR" <6>) has no record (\ref UUID7_DOC_SDP "SDP" <4.6>, OI-11).
